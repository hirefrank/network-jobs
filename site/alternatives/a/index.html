02

The pipeline

Résumé ──▶ profile + prefs interview        (who you are, what you want)
LinkedIn ZIP ──▶ company graph                 (312 connections → 87 companies)
      │──▶ careers-discover ──▶ triage/            (staged, never silent)
      │──▶ you review ──▶ jobs-ingest ──▶ corpus/  (confirmed only)
      └──▶ search ──▶ warm intro                      (ranked, forwardable)
STOPGATE: discover only stages. Nothing enters your corpus until you explicitly say so — review triage first, ingest second.
03

Six skills, one loop

skill_01

network-jobs-setup

Résumé → profile, plus a preferences interview grounded in your background: location, remote/hybrid, IC vs manager, former employers.

skill_02

network-jobs-import

LinkedIn Connections ZIP → local company graph. No PII ever leaves the machine.

skill_03

careers-discover

Model-driven career-page discovery. Handles JS-heavy boards via agent-browser. Stages, never ingests.

skill_04

jobs-ingest

Promotes a confirmed triage batch into normalized corpus shards. Only on your word.

skill_05

network-jobs

Searches your corpus with your prefs as defaults. Semantic matching optional via embed-setup.

skill_06

intro-email-generator

Forwardable warm-intro emails through real mutuals. The agent drafts — you send.

05

Local-first, for real

OK — no cloud account

Everything lives in ~/.network-jobs/: connections, companies, corpus, triage, profile, prefs, résumé. There is no hosted API to sign up for.

OK — your data stays home

Skills read local files. The only network calls are the career pages your agent visits — the same pages you'd open in a browser.

OK — model-agnostic

Use any model. Stronger ones discover career pages better; mid-tier is plenty for search and intros.

OK — free & MIT

Open source, local free. The only spend is the tokens your own agent uses.

06

faq

Does anything get uploaded anywhere?
No. Profile, résumé, and connections live in ~/.network-jobs/ and are never sent to a remote API. Discovery fetches public career pages, nothing more.
Which agents work?
Any agent that loads Agent Skills: Claude Code, Cursor, Codex, OpenCode, Pi, Gemini CLI, Hermes, and others. One setup --agent links all six skills into each of them.
Do I need LinkedIn Premium?
No. Use the free export: Settings → Data privacy → Get a copy of your data → Connections only. Then network-jobs import ~/Downloads/Connections.zip.
Which model should I use?
Yours. Prefer a stronger model for career-page discovery; mid-tier is usually enough for search and intro drafts.
Does it message people for me?
Never. It drafts a forwardable intro email naming a real mutual connection. Review it, send it yourself.
What does it cost?
The suite is free and MIT-licensed. You pay only for whatever your own agent model charges in tokens.
